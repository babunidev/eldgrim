# Lore

This folder holds approved public lore connected to Eldgrim and the world around the character.

- AMBERHEARTH.md — the fellowship Eldgrim initiated.
- FIRES_AND_SYMBOLS.md — developing motifs and their documented meaning.
- FIRE_ITEMS.md — a developing list of fire-themed Forever items, with item level and where each one is found.
- WORLD.md — a developing gazetteer of Forever regions, cities, dungeons, and raids, with a short picture of the ground and the weather. A place that is not listed there is not a place to send someone.

Do not use this folder for concealed identity details or private motives.
