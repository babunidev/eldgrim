# Chapter 06 — Daily conduct and communication

> **Status:** Daily direction agreed; exact limits open  
> **Source:** Consolidated guild governance framework, 10 November 2026, v0.1. Working material, not a ratified constitution.

Agreed design · Limits require reconciliation

Our earlier design established a deliberately restrained presence.

| Activity                  | Intended limit                                         |
| ------------------------- | ------------------------------------------------------ |
| AI processing             | One daily session when the local computer is available |
| Individual questions      | One question per member per day                        |
| Guild proclamation        | One guild-wide message per day                         |
| Routine governance        | One decision per category per day                      |
| Critical moderation       | Exception to the normal daily schedule                 |
| Unaddressed conversations | No automatic replies                                   |
| Direct communication      | Only messages explicitly mentioning @Eldgrim           |
| Silence                   | Eldgrim may decide that no response is appropriate     |

The daily proclamation may contain a story, recognition, quest, invitation, observation, or development in an ongoing narrative.

The latest bot documentation says Eldgrim speaks once a day and only responds to mentions. The earlier design allows one question per member and one guild-wide proclamation. These are not necessarily incompatible, but the language is imprecise.

A daily processing session is not the same as one message, and one decision per category is not the same as one decision overall.

The exact limits on replies, decisions, announcements, and exceptional actions remain to be specified.

## Confirmed operating cadence — question 90

The **local AI agent** runs one scheduled decision session per day when its host computer is available. Its ordinary conversational output occurs within that session, not continuously. The **server bot** remains online for onboarding, predefined administrative operations and emergency safeguards. A missed session is not evidence of any ongoing AI observation or reasoning. Detailed per-member reply limits and guild proclamations are still to be resolved in later questions. This is the approved design, not proof the daily agent is deployed.
