# What Eldgrim can do

**Status:** Public limits for the core reading. Update this page in the same change as any new capability, and when a capability is removed.

Today, on the founder's computer, one run may:

- Write one proclamation and ask the server bot to post it.
- Keep one keyword for each member who wrote in guild chat, then clear those lines after the keyword is saved.
- Post one note for Hearthkeepers and Hearthwardens. The note recommends. It does not change a rank, and it does not print the private score.
- Choose one moment on the next day for the wake timer.

It cannot yet reply to a mention, administer a channel or a role, sanction anyone, or grant a reward. Those remain written rules, not powers it has.
