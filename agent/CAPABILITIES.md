# What Eldgrim can do

**Status:** Public limits for the core reading. Update this page in the same change as any new capability, and when a capability is removed.

Today, on the founder's computer, one run may:

- Write one proclamation and ask the server bot to post it. The proclamation is told today's weekday and the coming Sunday. It welcomes a new character as the brief describes them, including the race and class on record, congratulates the level-ups the brief names, says how many Eldgrim quests those characters have completed, and invites the guild to that Sunday. If today is not Sunday, it does not call the gathering this evening. It does not give that gathering a theme, a region, or a place. It does not invent a name, a level, a count, a race, or a class. The score is not spoken.
- Keep one keyword for each character who wrote in guild chat, then clear those lines after the keyword is saved, whether or not the game is open. The addon fills the lists again. The keyword is about the character. It is not a note about the player, and it does not keep a real-world name or place. A line relayed by only one member does not back that keyword or the standing point.
- Post one note for Hearthkeepers and Hearthwardens. The note recommends. It does not change a rank, and it does not print the private score.
- Send one quest when a member has asked for one. The quest is for the member's one character; a private thread asks only whether to add a short wish. A member who still has several characters from before the Forge took one is asked which. That call sees only that character, and the wish is a wish, not an instruction. A later quest is shown only the fire items that character's level allows, by the level the catalog says an item needs, and an item above it is refused. It does not read the rest of the guild. One quest is open per member. The quest is posted as a reply to the ask in the Eldgrim channel. Add one private standing point when a different Amberhearth member has witnessed the screenshot with the Roar. Every rank that holds the Amberhearth role may do that. A member without the role does not. When that Roar lands, a fire is set on the quest and one private line says another may be asked for. The line names the quest when the daily run stored that line with it. The point is not spoken. Cancelling a quest sets it aside, says another may be asked for whenever the member wants, and does not offer a replacement. The score does not change.
- Record the weekly ember for a character when a different Amberhearth member has Roared that member's screenshot in the Eldgrim channel, sent with @Eldgrim and the word ember. A member who still has several characters chose which in a private thread; a picture still waiting for that choice waits, and after seven days it is dropped. The ember never finishes the member's own quest. Add one private standing point per member per ember week. Write the week and the character names into `EldgrimVerified.lua` in the addon installed on the founder's computer, and nothing else there. Jasmine Amberbrew's client sends that list to the guild at her next login. The point is not spoken.
- Name a region, city, or dungeon in a proclamation only from the world page read with that call. A quest is shown only the places its character's level and side allow, never a raid, a battleground or a place with no level, and a quest that names another place on the world page is refused for a safe one.
- Choose one moment on the next day for the wake timer.
- Reply once to each member who wrote in the Eldgrim channel, on their newest message, with Discord's reply. That call sees only the character chosen for that member. A member who wrote nothing is skipped. One short impression of the answered letter is kept on that character. The raw line is not. The player's real-world life is not kept. The conversation is not a direct message.

It cannot yet administer a channel or a role, sanction anyone, or hand out an item. Those remain written rules, not powers it has. It does not hold a conversation in direct messages. A short mention that says info, in the Eldgrim channel, is answered at once by direct message: who Eldgrim is, how to ask for a quest, and how the daily reply works. A mention in that channel is marked with a fire a few seconds later, so the member knows it was seen. A quest mention is not answered with text at once. A private thread asks whether to add a comment, and which character only for a member who still has several. The quest itself comes with the daily run, as a reply to that message, written for the member's character. A new character is kept at level 1 until the guild chat says otherwise. Quests already given to that member are remembered, and a new quest does not repeat one of them. The Eldgrim channel sits in the Roar and Amberhearth category, under talk, with that category's permissions.
